## ⚙️ Prerequisites & Setup

### Requirements
- Basic familiarity with `JavaScript`
- Git installed on your local machine

### Installation Steps
```bash
# 1. Clone repository
git clone https://github.com/JasminPeer/startup-portfolio.git
cd startup-portfolio

# 2. Install dependencies
npm install

# 3. Run application
npm start
# or npm run dev
```
